# Data Model: Services About Section Mobile Rework

No new entities, content types, or data shapes are introduced by this feature.

The `About` component's copy (eyebrow label, heading, body paragraph, signature, and the two certification logo labels/images) is existing hardcoded content in `app/routes/pages/services/components/about/index.tsx`. It is not Sanity-driven today and stays that way — this feature only changes the order and CSS layout of the existing markup, not what data it renders.
